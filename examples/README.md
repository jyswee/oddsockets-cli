# OddSockets — SDK quickstarts

A 60-second quickstart for every OddSockets SDK: install one-liner + a minimal
connect → subscribe → publish example, then a link to the full maintained SDK
repo with runnable examples.

> Prefer the terminal? The [`oddsockets` CLI](../README.md) gives you pub/sub,
> presence and history over any channel — no code required.

Every example connects through the OddSockets manager
(`connect.oddsockets.tyga.network`), which load-balances you onto a worker
automatically — you only ever supply an API key.
